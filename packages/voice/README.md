# @videoforge/voice

Adapter kết nối trực tiếp tới Voice Studio (`http://192.168.5.18:3900`), quản lý Voice Pool (`_nam` / `_nu`), thuật toán tự động xoay cặp giọng `pickCast` với `seededRng`, xử lý ghép segment audio (khoảng nghỉ 120–200ms, crossfade 30–50ms, chuẩn hóa −16 LUFS) và đồng bộ mốc thời gian từng từ cho Caption Agent.
