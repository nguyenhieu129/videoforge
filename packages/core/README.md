# @videoforge/core

Package chứa toàn bộ định nghĩa kiểu dữ liệu (TypeScript types), Zod schemas cho 17 AI Agents, hằng số hệ thống, mã hóa AES-256-GCM cho API key và các hàm tiện ích dùng chung.

## Cách sử dụng

```ts
import { ScriptSchema, StoryboardSchema, encryptSecret, decryptSecret } from '@videoforge/core';
```
