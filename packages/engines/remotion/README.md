# @videoforge/engine-remotion

Engine Remotion cho các loại cảnh biểu đồ và số liệu có tham số (Mục 7.2):
- Các template React có sẵn: `BarChartRace`, `Counter`, `Leaderboard` trong `compositions/`.
- Nhận `props` JSON từ Storyboard và chạy `npx remotion render`.
- Lưu ý: Kiểm tra giấy phép Remotion trước khi dùng cho mục đích thương mại.
